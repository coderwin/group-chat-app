# Group Chat App

여러 사람이 함께 대화할 수 있는 채팅 앱 프로젝트입니다.

## 프로젝트 상태

프로젝트 초기 설정을 완료했습니다. 채팅 기능은 앞으로 구현할 예정입니다.
## 개발 계획

- Next.js와 Socket.IO 기반 실시간 채팅 앱 구현
- 채팅 화면, 메시지 전송, 접속자 표시 추가
- 여러 브라우저 창으로 테스트 후 기능 단위 커밋
- 향후 로그인, 여러 채팅방, 데이터베이스 저장 기능 확장

## 진행 순서

1. 기본 프로젝트 구조와 로컬 실행 환경 구성
2. 채팅 메시지 목록과 입력 UI 구현
3. Socket.IO를 이용한 실시간 메시지 전달 구현
4. 접속자 입장 및 퇴장 상태 표시
5. 여러 브라우저 창에서 테스트
6. 기능 단위로 커밋하고 `main` 브랜치에 푸시

## 향후 확장 기능

- 회원가입과 로그인
- 여러 채팅방 생성 및 참여
- 메시지 데이터베이스 저장
- 메시지 검색과 알림
